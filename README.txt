相手選出スキャン（オフライン・AIなし・無料）
=============================================
使い方（初回）
 1. 「枠合わせ」タブ：相手側スクショで6枠が緑ワクに合うか確認（この端末は初期値でOK）
 2. 「図鑑を教える」タブ：スクショを読み込み、6枠に正しい名前を割り当てて「覚えさせる」
    → 対戦を重ねるほど図鑑が埋まり、判定精度が上がります（色違いは別登録）
使い方（対戦中）
 3. 選出画面をスクショ → 背面ダブルタップ等でこのアプリを開く
 4. 「スキャン」タブでそのスクショを選ぶ → 6体を自動判定（間違いは手で修正）
 5. 推奨選出（コア＋3枠目候補＋各相手への最適解）が出ます

判定の仕組み：各枠を32x32グレーに正規化し、教えた見た目との距離で最近傍照合。
 同じゲーム画面・同じ絵柄同士なので高精度。d値が小さいほど確信度が高い。

設置（ホーム画面インストール）：champions-pwa と同じ手順。
 GitHub Pages 等のHTTPSに置き、Safariで開いて「ホーム画面に追加」。

注意：あなたの並び（左側）は固定前提でアプリ内に登録済み。認識するのは相手（右側）のみ。
 選出評価はSTABベースの簡易版。細かい確定数はダメージ計算アプリ側で詰めてください。
